📋
프로젝트 진행 현황 태스크 목록과 완료율이 담긴 엑셀을 차트로 바꿔 팀 보고에 사용.

사용법 — 딱 3단계

1
엑셀 파일 업로드 xlsx, xls, csv 형식을 지원합니다. 파일을 드래그 앤 드롭하거나 버튼을 눌러 선택하세요. 처음이라면 샘플 파일로 먼저 체험해보세요.
2
자동 분석 확인 헤더 행과 날짜·금액·수량 컬럼을 자동으로 감지합니다. 컬럼 타입이 잘못 인식된 경우 우측 설정 패널에서 수동 조정 가능합니다.
3
테마 선택 후 저장 그린·퍼플·오션·로즈·엠버 5가지 테마 중 선택하세요. 완성된 대시보드는 PNG 이미지로 저장하거나 화면에서 바로 인쇄할 수 있습니다.

주요 기능

  • ✓8가지 차트 자동 생성 — 막대, 누적 막대, 라인, 영역, 파이, 도넛, 산점도, 히트맵
  • ✓컬럼 자동 인식 — 날짜 형식, 금액(원/달러), 수량·비율 컬럼을 자동 구분
  • ✓5가지 색상 테마 — 보고 목적에 맞는 분위기로 전환 가능
  • ✓PNG 이미지 저장 — 대시보드 전체를 고화질 이미지로 내보내기
  • ✓KO / EN 인터페이스 — 한국어·영어 전환 지원
  • ✓서버 전송 없음 — 파일이 인터넷으로 나가지 않아 기밀 자료도 안심 사용

지원 파일 형식 및 제한

xlsx / xls

Excel 2007 이상 (.xlsx) 및 구버전 (.xls) 지원

csv

쉼표 구분 텍스트 파일. UTF-8 및 EUC-KR 한글 인코딩 지원

권장 구조

1행이 헤더(항목명), 2행부터 데이터. 시트가 여러 개면 첫 번째 시트를 사용

파일 크기

브라우저 메모리 한도 내에서 처리. 일반적으로 10MB / 50,000행 이내 권장

자주 묻는 질문 (FAQ)

파일이 서버로 전송되지 않는다는 게 사실인가요?

네, 사실입니다. Excel Dashboard Builder는 JavaScript로만 동작하며, 업로드한 파일은 브라우저의 메모리에서만 읽고 처리됩니다. 외부 서버에 네트워크 요청을 보내지 않으므로, 인터넷이 끊긴 상태(오프라인)에서도 사용 가능합니다.

한글이 포함된 엑셀 파일도 제대로 불러와지나요?

xlsx/xls 형식은 유니코드 기반이라 한글이 정상적으로 처리됩니다. CSV 파일의 경우 저장 시 UTF-8 인코딩을 선택하시면 됩니다. EUC-KR로 저장된 CSV도 내부적으로 자동 변환을 시도합니다.

차트 종류는 어떻게 바꾸나요?

대시보드가 생성된 후, 각 차트 카드 우측 상단의 아이콘을 클릭하면 해당 차트의 종류를 막대·라인·파이·도넛 등으로 변경할 수 있습니다.

데이터가 너무 많아서 차트가 느린데 어떻게 하나요?

50,000행 이상이거나 컬럼이 매우 많은 경우 렌더링이 느려질 수 있습니다. 엑셀에서 분석에 필요한 컬럼만 남기거나, 기간을 잘라서 여러 파일로 나눠 불러오는 방법을 권장합니다.

저장한 PNG를 파워포인트에 바로 쓸 수 있나요?

네. PNG로 내보낸 이미지는 PowerPoint, Keynote, Google Slides 등에 바로 삽입할 수 있습니다. 배경이 어두운 다크 테마와 밝은 테마 모두 제공하므로 보고서 스타일에 맞게 선택하세요.

모바일에서도 사용할 수 있나요?

기본적인 업로드와 차트 확인은 모바일 브라우저에서도 가능합니다. 다만 대형 데이터나 세밀한 차트 설정은 PC 환경을 권장합니다.

무료인가요? 광고가 붙는 이유가 뭔가요?

완전 무료입니다. 서비스 유지 및 개선 비용을 충당하기 위해 Google AdSense 광고를 게재하고 있습니다. 워터마크 없이, 모든 기능을 제한 없이 사용할 수 있습니다.

기능 추가나 버그 제보는 어디서 하나요?

연락처 페이지로 문의 주시면 확인 후 반영합니다. 특히 "이런 차트가 있었으면 좋겠다", "이 데이터 형식이 안 읽힌다"는 피드백을 적극 수집하고 있습니다.
