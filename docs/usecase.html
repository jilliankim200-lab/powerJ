스마트스토어 / 이커머스

판매·주문 분석

스마트스토어, 쿠팡 파트너스, 자사몰 등 온라인 판매 데이터를 분석해 어떤 상품이 잘 팔리고, 어느 채널에서 고객이 오는지 파악할 수 있습니다.

엑셀 데이터 구성 방법

각 플랫폼의 정산 내역 또는 주문 내역을 다운로드한 후 아래 컬럼 구조로 정리하세요.

컬럼명타입예시설명
주문일날짜2026-03-15YYYY-MM-DD 형식 권장
카테고리텍스트의류, 식품, 전자기기5개 이내로 분류
상품명텍스트린넨 셔츠상세 분석 시 사용
수량숫자3정수로 입력
판매가(원)숫자35000단가 기준
매출(원)숫자105000수량 × 판매가
판매채널텍스트네이버, 쿠팡, 자사몰채널별 비교용

추천 차트 구성

월별 매출 추이 → 라인 차트 카테고리별 매출 비중 → 파이 차트 채널별 판매량 비교 → 막대 차트 상품별 판매 순위 → 수평 막대 차트
실전 팁 스마트스토어 정산 내역 엑셀은 컬럼이 많고 형식이 복잡합니다. 분석에 필요한 컬럼(주문일, 카테고리, 매출금액)만 새 시트에 복사해서 업로드하세요. 합계 행이 중간에 있으면 삭제 후 사용하세요.

제조업 / 생산관리

생산·재고·품질

생산량, 불량률, 재고 현황을 시각화해 생산 라인의 효율성을 파악하고 재고 과부족을 조기에 발견할 수 있습니다.

생산 실적 데이터 구성

컬럼명타입예시설명
생산일날짜2026-03-20일별 집계 기준
제품코드텍스트P-001품목 구분자
라인텍스트A라인, B라인설비 단위 구분
생산목표숫자1000계획 수량
생산실적숫자940실제 생산량
불량수숫자12불량 개수
달성률(%)숫자94실적/목표×100

추천 차트 구성

일별 생산실적 추이 → 라인 차트 라인별 달성률 비교 → 막대 차트 불량 유형별 비중 → 파이 차트 목표 vs 실적 → 누적 막대
실전 팁 달성률(%)과 같은 비율 컬럼은 라인 차트로, 생산수량과 같은 절대값은 막대 차트로 분리해서 보는 것이 더 명확합니다. 두 컬럼을 같은 차트에 넣으면 Y축 스케일이 달라 왜곡될 수 있습니다.
🍽️

음식점 / 카페

매출·메뉴 분석

POS 시스템에서 매출 데이터를 내려받아 메뉴별 인기도, 시간대별 혼잡도, 요일별 매출 패턴을 파악할 수 있습니다.

POS 데이터 정리 방법

컬럼명타입예시설명
주문일시날짜2026-03-15날짜 부분만 추출해도 됨
요일텍스트월, 화, 수히트맵 분석용
시간대텍스트점심, 저녁또는 11시, 12시 등
메뉴텍스트아메리카노카테고리로 묶어도 됨
수량숫자5판매 건수
매출(원)숫자25000수량 × 단가

추천 차트 구성

메뉴별 판매 비중 → 파이/도넛 차트 요일×시간대 혼잡도 → 히트맵 월별 매출 추이 → 라인 차트 메뉴별 매출 순위 → 막대 차트
실전 팁 요일×시간대 히트맵은 특히 강력합니다. 언제 인력을 더 배치해야 할지, 어느 시간대에 이벤트를 해야 할지 한눈에 보입니다. 요일 컬럼(월~일)과 시간대 컬럼(11시~22시)이 있으면 히트맵 차트를 선택하세요.
🎓

교육기관 / 학원

수강·성적 분석

수강생 현황, 성적 분포, 출석률을 시각화해 교육 효과를 측정하고 관리가 필요한 학생을 조기에 파악할 수 있습니다.

학생 데이터 구성

컬럼명타입예시설명
반/과목텍스트영어A반, 수학B반그룹 구분
학년텍스트중1, 고2또는 숫자 학년
성별텍스트남, 여
중간고사숫자85점수(0~100)
기말고사숫자91점수(0~100)
출석률(%)숫자95백분율
등급텍스트A, B, C성취도 구분

추천 차트 구성

등급별 학생 분포 → 파이 차트 반별 평균 성적 → 막대 차트 중간·기말 점수 변화 → 라인 차트 출석률 vs 성적 → 산점도

인사 / HR

조직·인원 현황

부서별 인원 구성, 연봉 분포, 근속 연수 분석으로 조직 현황 보고서를 빠르게 만들 수 있습니다.

추천 차트 구성

부서별 인원 비중 → 도넛 차트 직급별 연봉 분포 → 막대 차트 연도별 신규 입사자 추이 → 라인 차트 성별×직급 분포 → 누적 막대
개인정보 주의 실제 직원 정보를 업로드할 때는 이름, 주민번호, 연락처 등 식별 가능한 정보는 제거하거나 익명화하세요. PowerJ Tools는 파일을 서버로 전송하지 않지만, 화면에 표시되므로 공용 PC에서는 주의가 필요합니다.
📣

마케팅 / 광고팀

성과·ROAS 분석

채널별 광고 성과를 비교하고 ROAS(광고비 대비 매출)를 시각화해 예산 배분 의사결정을 데이터로 지원할 수 있습니다.

광고 성과 데이터 구성

컬럼명타입예시설명
월날짜/텍스트2026-03월 단위 집계
채널텍스트네이버, 구글, 인스타광고 플랫폼
캠페인텍스트브랜드, 전환, 리타겟캠페인 유형
광고비(원)숫자2500000집행 예산
클릭수숫자8500클릭 수
전환수숫자320구매/가입 수
매출(원)숫자12000000전환 기여 매출

추천 차트 구성

채널별 광고비 비중 → 도넛 차트 월별 ROAS 추이 → 라인 차트 채널별 전환수 비교 → 막대 차트 광고비 vs 매출 → 산점도
실전 팁 ROAS = 매출 / 광고비 컬럼을 미리 엑셀에서 계산해서 추가하면 라인 차트로 바로 시각화할 수 있습니다. Google Analytics, 네이버 광고 모두 csv 내보내기를 지원하니 직접 다운로드해 사용하세요.
