1. 엑셀 파일 준비하기 — 잘 읽히는 데이터 구조

대시보드 자동 생성이 잘 되려면 파일 구조가 중요합니다. PowerJ Tools는 아래 구조를 기준으로 헤더와 데이터를 자동 인식합니다.

권장 파일 구조

  • 1행 = 헤더(컬럼명) — "날짜", "매출", "팀", "제품" 등 명확한 이름을 사용하세요.
  • 2행부터 = 데이터 — 빈 행 없이 연속으로 작성하세요.
  • 숫자 컬럼은 숫자 서식으로 — 텍스트 서식으로 저장된 숫자는 차트에 표시되지 않습니다.
  • 날짜는 날짜 서식으로 — 엑셀의 날짜 서식(YYYY-MM-DD 등)을 사용하면 날짜 컬럼으로 자동 인식됩니다.
  • 병합 셀 사용 금지 — 병합된 셀은 오인식의 원인이 됩니다. 사용 전 모두 해제하세요.
Tip 컬럼명에 단위를 붙이면 자동 인식에 유리합니다. 예: "매출(원)", "수량(개)", "비율(%)"처럼 작성하면 차트 축 레이블도 명확해집니다.

피해야 할 구조

  • 첫 몇 행이 제목이나 빈 행으로 시작하는 경우 → 2행 이후부터 데이터가 되어야 함
  • 합계 행이 데이터 중간에 섞여 있는 경우 → 합계 행은 삭제하거나 별도 시트로 분리
  • 하나의 셀에 여러 값이 들어있는 경우 (예: "서울/부산") → 각 행에 하나씩 분리
  • 컬럼 수가 수십 개 이상인 경우 → 필요한 컬럼만 남기거나 별도 분석용 시트로 정리

2. 차트 종류 선택 가이드

데이터의 성격에 따라 적합한 차트가 다릅니다. 잘못된 차트는 데이터를 오해하게 만듭니다.

막대 차트 (Bar)
항목 간 크기 비교에 최적. 팀별 매출, 제품별 판매량처럼 범주형 데이터를 비교할 때 사용하세요.
예: 영업팀별 분기 매출 비교
누적 막대 차트 (Stacked Bar)
전체 합계와 각 부분의 비중을 동시에 보고 싶을 때. 제품군별 지역 매출 구성처럼 두 개 이상의 분류가 겹칠 때 유용합니다.
예: 월별 카테고리별 매출 구성
라인 차트 (Line)
시간에 따른 변화 추이를 보여줄 때. 날짜 컬럼이 있고 값의 흐름을 보고 싶을 때 가장 적합합니다.
예: 월별 방문자 수 변화
영역 차트 (Area)
라인 차트와 유사하지만 면적으로 누적량을 강조할 때. 여러 항목의 합계 변화를 시각화합니다.
예: 채널별 누적 매출 흐름
파이 차트 (Pie)
전체 대비 각 항목의 비율을 보여줄 때. 항목이 5개 이하일 때 효과적입니다. 항목이 많으면 도넛 차트를 권장합니다.
예: 제품별 매출 비중
도넛 차트 (Donut)
파이 차트와 동일하지만 중앙 공간에 합계나 주요 수치를 표시할 수 있어 더 가독성이 좋습니다.
예: 카테고리별 지출 구성
산점도 (Scatter)
두 수치 변수 간의 상관관계를 파악할 때. "광고비와 매출의 관계"처럼 X/Y 두 수치 컬럼이 있을 때 유용합니다.
예: 광고비 vs. 전환수 상관관계
히트맵 (Heatmap)
두 범주형 변수의 교차 지점에서 값의 강도를 색으로 표현. 요일×시간대별 주문 집중도 분석 등에 사용합니다.
예: 요일별·시간대별 매출 강도
주의 파이/도넛 차트는 항목이 6개 이상이면 각 조각이 너무 작아져 가독성이 떨어집니다. 이 경우 하위 항목을 "기타"로 묶거나 막대 차트로 전환하는 것이 낫습니다.

3. PowerJ Tools 대시보드 생성 단계별 가이드

1
엑셀 파일 업로드 또는 샘플 테스트 홈 페이지에서 파일을 드래그&드롭하거나 버튼을 클릭해 업로드하세요. 처음이라면 "샘플로 먼저 테스트하기"를 클릭해 영업 데이터 샘플로 먼저 기능을 체험할 수 있습니다. xlsx, xls, csv 형식을 지원하며 파일은 서버로 전송되지 않습니다.
2
자동 분석 결과 확인 업로드 즉시 헤더 행과 각 컬럼의 데이터 타입(날짜·숫자·텍스트·금액)을 자동으로 감지하고 8가지 차트를 자동 배치합니다. 컬럼 인식이 잘못된 경우 우측 설정 버튼에서 직접 조정할 수 있습니다.
3
차트 커스터마이징 각 차트 카드의 편집 아이콘을 클릭하면 차트 종류 변경, X축·Y축 컬럼 선택, 제목 수정이 가능합니다. 차트를 드래그해 순서를 바꾸거나 오른쪽 하단을 드래그해 크기를 조절할 수도 있습니다. 필요 없는 차트는 삭제하고 새로운 차트를 추가할 수도 있습니다.
4
테마 선택 상단 도구모음에서 그린(기본), 퍼플, 오션, 로즈, 엠버 5가지 테마를 선택할 수 있습니다. 발표용은 어두운 다크 계열, 인쇄용은 밝은 계열 테마를 권장합니다.
5
이미지 또는 HTML 저장 우측 상단 저장 버튼에서 PNG 이미지 또는 HTML 파일로 내보낼 수 있습니다. PNG는 PPT·이메일 첨부용, HTML은 웹에 그대로 올리거나 보존용으로 활용하세요. 저장된 PNG는 PowerPoint, Keynote, Google Slides에 바로 삽입 가능합니다.

4. 실전 팁 10가지

  1. 날짜는 엑셀 날짜 서식으로 저장하세요. "2024-01", "2024년 1월"처럼 텍스트로 저장된 날짜도 인식되지만, 엑셀 날짜 서식(날짜 셀)이 더 안정적으로 처리됩니다.
  2. 금액 컬럼에 쉼표·원화 기호가 있어도 괜찮습니다. "1,234,000원" 형식도 자동으로 숫자로 변환합니다.
  3. 같은 데이터를 여러 기준으로 보려면 차트를 복수 추가하세요. "팀별 매출"과 "제품별 매출"을 동시에 보는 대시보드를 만들 수 있습니다.
  4. 피벗 테이블로 미리 집계하면 더 깔끔한 차트가 나옵니다. 원시 데이터(raw data)를 그대로 넣어도 자동 집계되지만, 엑셀에서 미리 피벗 테이블로 정리한 뒤 업로드하면 더 정확합니다.
  5. 파이 차트는 상위 5개만 보여주세요. 항목이 많으면 나머지를 "기타"로 묶은 데이터를 별도로 만들어 업로드하면 훨씬 보기 좋습니다.
  6. 인쇄할 때는 브라우저 인쇄 기능(Ctrl+P)을 활용하세요. PNG보다 선명하게 출력됩니다. 배경 그래픽 인쇄 옵션을 켜야 차트 색상이 살아납니다.
  7. 같은 파일을 다른 테마로 저장해보세요. 같은 데이터도 테마에 따라 다른 느낌을 줍니다. 발표 자료에 따라 테마를 바꿔 두 버전을 저장해두면 유용합니다.
  8. 열이 너무 많으면 필요한 것만 남기세요. 20개 이상의 컬럼이 있는 파일은 분석에 필요한 5~10개 컬럼만 복사해 새 시트로 만든 뒤 업로드하면 더 빠르고 정확합니다.
  9. 오프라인에서도 사용 가능합니다. 사이트를 한 번 열고 파일을 업로드한 뒤에는 인터넷 없이도 차트를 조작하고 저장할 수 있습니다.
  10. 저장한 HTML은 그대로 공유할 수 있습니다. HTML 다운로드 기능으로 저장한 파일은 차트와 데이터가 모두 포함된 단독 파일입니다. 이메일에 첨부하거나 사내 공유 드라이브에 올려 팀원들과 공유하세요.

5. 자주 발생하는 오류와 해결법

증상 원인 해결법
차트가 텅 비어있음 Y축으로 인식되어야 할 숫자 컬럼이 텍스트로 저장됨 엑셀에서 해당 컬럼 선택 → 셀 서식 → 숫자로 변경 후 재저장
한글이 깨져서 나옴 CSV 파일 인코딩이 EUC-KR 엑셀에서 "CSV UTF-8(쉼표로 분리)"으로 다시 저장
파일 열기 실패 파일이 다른 앱에서 열려 있거나 손상됨 다른 앱을 모두 닫고 재시도. 오류 지속 시 다른 브라우저 사용
날짜가 숫자(44927 등)로 표시됨 엑셀 내부 날짜 시리얼 번호가 그대로 노출됨 엑셀에서 해당 셀의 서식을 "날짜"로 명시적으로 설정 후 재저장
차트 렌더링이 매우 느림 데이터 행 수가 50,000행 초과 또는 컬럼이 매우 많음 필요한 기간/컬럼만 필터링한 후 업로드. Chrome 브라우저 권장
파이 차트에 항목이 너무 많이 표시됨 범주형 컬럼의 고유값이 10개 이상 상위 5개 항목만 남기고 나머지를 "기타"로 묶은 데이터를 미리 준비
PNG 저장 시 차트가 잘림 브라우저 창 크기가 너무 작음 브라우저를 최대화하거나 확대/축소를 100%로 맞춘 후 저장

6. QR / 바코드 생성기 활용법

QR / 바코드 생성기는 엑셀 파일을 업로드하면 행 단위로 QR코드 또는 바코드를 자동 생성하는 도구입니다. 재고 라벨, 자산 태그, 제품 스티커 등 다양하게 활용할 수 있습니다.

활용 시나리오

  • 재고 라벨 인쇄 — 품목코드, 제품명, 위치 정보가 담긴 엑셀을 업로드하면 각 행마다 QR코드가 담긴 라벨이 생성됩니다. 브라우저 인쇄로 A4 라벨지에 바로 출력하세요.
  • URL QR 코드 대량 생성 — 여러 제품 페이지의 URL을 엑셀 컬럼에 넣고 업로드하면 URL별 QR코드를 한 번에 생성합니다.
  • 사원증/명함 QR — 이름, 연락처, 소속 등을 컬럼으로 정리한 뒤 업로드하면 개인별 QR코드를 대량 제작할 수 있습니다.
  • 바코드 라벨 — 상품코드(숫자 또는 문자)가 담긴 컬럼으로 Code 128, EAN-13 등 바코드를 즉시 생성합니다.
Tip QR코드에 넣을 데이터가 길수록 패턴이 복잡해져 인식률이 낮아집니다. URL은 단축 URL(bit.ly 등)을 사용하고, 텍스트 정보는 핵심 내용만 담아 100자 이내로 유지하는 것을 권장합니다.
