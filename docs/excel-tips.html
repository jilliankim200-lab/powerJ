엑셀 함수 완전 정복

업무 필수 함수를 실전 예시와 함께 — 대시보드 데이터 준비에 바로 활용하세요.

목차

  1. SUMIF / SUMIFS — 조건부 합계
  2. COUNTIF / COUNTIFS — 조건부 개수
  3. VLOOKUP / XLOOKUP — 데이터 찾기
  4. IF / IFS — 조건 분기
  5. TEXT / 날짜 함수 — 형식 변환
  6. 피벗 테이블 — 집계 자동화
  7. 엑셀 단축키 모음

SUMIF / SUMIFS

기초

특정 조건을 만족하는 셀들의 합계를 계산합니다. 대시보드 데이터를 팀별·제품별·월별로 집계할 때 가장 많이 사용하는 함수입니다.

기본 문법

=SUMIF(조건범위, 조건, 합계범위)
=SUMIFS(합계범위, 조건범위1, 조건1, 조건범위2, 조건2, ...)

실전 예시

목표수식설명
영업1팀 매출 합계=SUMIF(B:B,"영업1팀",C:C)B열에서 "영업1팀"인 행의 C열 합계
2026년 1분기 이익 합계=SUMIFS(D:D,A:A,"1분기",B:B,2026)두 조건 동시 적용
매출 100만 이상 건의 합계=SUMIF(C:C,">="&1000000,C:C)비교 연산자 사용
결과숫자로 반환텍스트 서식 셀은 계산에서 제외됨
대시보드 활용 팁 원시 데이터 시트 따로, SUMIFS로 집계한 결과 시트 따로 만드세요. 집계 결과 시트를 PowerJ Tools에 업로드하면 훨씬 깔끔한 차트가 나옵니다.

COUNTIF / COUNTIFS

기초

조건을 만족하는 셀의 개수를 셉니다. 설문 결과 집계, 등급별 인원 수, 특정 상태의 건수를 파악할 때 사용합니다.

기본 문법

=COUNTIF(범위, 조건)
=COUNTIFS(범위1, 조건1, 범위2, 조건2, ...)

실전 예시

목표수식
A등급 학생 수=COUNTIF(D:D,"A")
영업1팀 중 목표 달성 건수=COUNTIFS(A:A,"영업1팀",C:C,">="&B2)
빈 셀 개수=COUNTIF(A:A,"")
중복값 개수 확인=COUNTIF(A:A,A2) → 2 이상이면 중복

VLOOKUP / XLOOKUP

중급

한 표에서 값을 찾아 다른 열의 값을 가져옵니다. 제품 코드로 제품명 가져오기, 직원 ID로 부서 가져오기 등에 사용합니다.

VLOOKUP 문법

=VLOOKUP(찾는값, 범위, 열번호, [일치방식])
'일치방식: 0 = 완전일치(권장), 1 = 근사일치

XLOOKUP 문법 (Excel 2021 이상, Microsoft 365)

=XLOOKUP(찾는값, 검색범위, 반환범위, [없을때값])
' VLOOKUP보다 유연하고 오류 처리가 편함

실전 예시

목표VLOOKUP 수식XLOOKUP 수식
품목코드로 제품명 가져오기=VLOOKUP(A2,제품표!A:C,2,0)=XLOOKUP(A2,제품표!A:A,제품표!B:B,"없음")
직원ID로 부서 가져오기=VLOOKUP(B2,직원표!A:D,3,0)=XLOOKUP(B2,직원표!A:A,직원표!C:C)
VLOOKUP 주의사항 찾는 값이 반드시 범위의 첫 번째 열에 있어야 합니다. 왼쪽 열을 가져오려면 INDEX+MATCH 또는 XLOOKUP을 사용하세요. 또한 숫자를 텍스트로 저장한 경우 찾기 실패(#N/A)가 납니다.

IF / IFS

기초

조건에 따라 다른 값을 반환합니다. 등급 부여, 달성 여부 판단, 카테고리 분류 등에 활용합니다.

기본 문법

=IF(조건, 참일때값, 거짓일때값)
=IFS(조건1, 값1, 조건2, 값2, ...) ' 다중 조건

실전 예시

목표수식
매출 목표 달성 여부=IF(C2>=D2,"달성","미달성")
점수를 등급으로 변환=IFS(B2>=90,"A",B2>=80,"B",B2>=70,"C",B2>=60,"D",TRUE,"F")
빈 셀이면 0, 아니면 원래 값=IF(A2="",0,A2)
특정 값이면 "해당", 아니면 빈칸=IF(A2="서울","해당","")

TEXT / 날짜 함수

중급

숫자나 날짜를 원하는 형식의 텍스트로 변환하거나, 날짜에서 연·월·일·요일을 추출합니다. 대시보드 데이터 준비에 매우 유용합니다.

날짜 관련 주요 함수

함수예시결과
YEAR=YEAR(A2)2026
MONTH=MONTH(A2)3 (3월)
TEXT (월 표시)=TEXT(A2,"YYYY-MM")2026-03
TEXT (요일 표시)=TEXT(A2,"AAA")월 (한국어 요일)
EOMONTH (월말)=EOMONTH(A2,0)해당 월 마지막 날
WEEKDAY=WEEKDAY(A2,2)1=월요일, 7=일요일
월별 집계를 위한 YYYY-MM 컬럼 추가 일별 데이터를 월별로 집계하려면 날짜 컬럼 옆에 =TEXT(A2,"YYYY-MM") 컬럼을 추가하세요. 이 컬럼을 X축으로 쓰면 월별 막대·라인 차트를 바로 만들 수 있습니다.

피벗 테이블

고급

수천 행의 원시 데이터를 드래그 앤 드롭으로 즉시 집계합니다. 함수 없이 팀별·월별·제품별 합계를 1분 만에 만들 수 있어 대시보드 준비에 가장 강력한 도구입니다.

피벗 테이블 만드는 방법

  1. 데이터 범위 아무 셀 클릭 → 삽입 → 피벗 테이블
  2. 새 시트에 생성 선택 후 확인
  3. 오른쪽 필드 목록에서 행에 팀/월 등 범주 컬럼 드래그
  4. 값에 매출/수량 등 숫자 컬럼 드래그 (자동으로 합계 계산)
  5. 완성된 피벗 결과를 복사 → 다른 시트에 값으로 붙여넣기 → PowerJ Tools 업로드
피벗 결과를 업로드할 때 주의 피벗 테이블 자체를 업로드하면 인식이 어렵습니다. 피벗 결과를 선택 후 복사 → 새 시트에 선택하여 붙여넣기 → 값으로 붙여넣은 다음 그 시트를 xlsx로 저장해 업로드하세요.
