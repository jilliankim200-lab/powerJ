응답 시간

본 서비스는 개인이 운영하는 무료 프로젝트로, 모든 문의에 24~72시간 내로 답변드리는 것을 목표로 합니다. 버그 제보의 경우 재현에 필요한 사용하신 브라우저, 업로드한 파일의 형식, 에러가 발생한 상황을 함께 적어주시면 훨씬 빠르게 해결할 수 있습니다.

문의 시 참고사항

  • 엑셀 파일에 민감 정보가 포함된 경우, 재현이 가능한 최소한의 샘플 파일을 만들어 보내주세요.
  • 도구의 모든 처리는 브라우저 내에서 이루어지므로, 저희는 이용자가 업로드한 원본 파일을 확인할 수 없습니다. 따라서 문제 재현에는 제공해주시는 정보가 중요합니다.

자주 묻는 질문

파일이 서버로 전송되지 않는다는 게 정말인가요?

네, 사실입니다. PowerJ Tools의 모든 도구는 순수 JavaScript로만 동작하며, 서버에 아무것도 업로드되지 않습니다. 브라우저 개발자 도구(F12 → Network 탭)를 열어 직접 확인하시면 파일 관련 외부 요청이 전혀 없다는 것을 볼 수 있습니다.

엑셀 파일이 읽히지 않아요. 어떻게 해야 하나요?

다음을 확인해주세요. ① 파일 형식이 xlsx, xls, csv인지 확인 ② 파일이 다른 프로그램에서 열려 있지 않은지 확인 ③ csv의 경우 저장 시 UTF-8 인코딩으로 저장 ④ 1행이 헤더(컬럼명)인지 확인. 위 사항을 모두 확인했는데도 문제가 계속되면 파일 형식과 오류 메시지를 이메일로 보내주세요.

차트가 이상하게 그려져요. 숫자가 텍스트로 읽히는 것 같아요.

엑셀에서 숫자 셀에 텍스트 서식이 적용된 경우 발생합니다. 해당 컬럼을 선택 → 서식을 "숫자" 또는 "일반"으로 변경 후 다시 저장해보세요. 또는 해당 컬럼의 셀을 선택해 좌측 상단 느낌표(!) 아이콘이 보이면 "숫자로 변환"을 클릭하면 됩니다.

한글 컬럼명이 깨져서 나와요.

xlsx/xls 파일은 한글이 정상 처리됩니다. csv 파일에서 한글이 깨지는 경우, 엑셀에서 "다른 이름으로 저장" → "CSV UTF-8(쉼표로 분리)"을 선택해 저장하면 해결됩니다. 일부 구버전 엑셀에서는 이 옵션이 없을 수 있으며, 이 경우 메모장에서 파일을 열고 "인코딩: UTF-8"로 다시 저장해보세요.

QR코드가 스캔이 안 돼요.

QR코드 크기가 너무 작게 인쇄된 경우 스캔 실패가 발생합니다. 인쇄 설정에서 "실제 크기(100%)"로 출력하거나, 한 페이지당 QR 수를 줄여 크기를 키워보세요. 또한 내용이 너무 긴 문자열(300자 이상)을 QR에 넣으면 패턴이 복잡해져 스캔이 어려울 수 있습니다. URL이나 짧은 코드 값 사용을 권장합니다.

기능 추가 요청은 어떻게 반영되나요?

이메일로 기능 요청을 보내주시면 요청 내용을 취합하여 우선순위가 높은 기능부터 순차적으로 개발합니다. 특히 "이런 데이터를 쓰는데 이런 차트가 있으면 좋겠다"는 구체적인 사용 사례가 있으면 반영 가능성이 높아집니다.
